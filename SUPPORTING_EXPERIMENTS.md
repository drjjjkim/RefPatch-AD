# Supporting experiments

Use the prediction and evaluation commands in the [README](README.md). Add the same option to both commands. The normal references, query order and expected geometry come from the dataset manifests.

| Manuscript result | Prediction and evaluation options | Recorded evidence |
|---|---|---|
| Table 2, full-image comparison | Default `--suite main --cohort original`, both datasets, groups 0–2 | `results/mvtec.csv` and `results/visa.csv` |
| Table 3, global and shuffled controls | `--suite weighting`, both datasets, original groups 0–2. The position permutation uses seed 20261102 and is shared across layers. | `metrics.csv`, experiment `weighting`. Uniform and local values use the default suite. |
| Table 4, additional reference cohort | `--cohort additional`, both datasets, groups 0–2 | `metrics.csv`, experiment `additional`. The weighting intervals are recalculated from the paired rows. |
| Table 5, timing | Fixed group 0, first query per class. The online experiment used an A40 and four CPU threads, two warm-up rounds and five recorded rounds. The incremental CPU post-processing used precomputed distances and indices. | `online_timing.json` and `cpu_timing.json`. Reaggregate the fixed observations with `supporting_results.py`. |
| Table 6, query mask sensitivity | `--suite mask --group 0` with original references. Exact distances and the layer mean are computed in float64 before the output map is cast to float32. | `metrics.csv`, experiment `mask`. These values use the mask experiment's arithmetic. |
| Table 7, alternative scoring | `--suite scoring`, original groups 0–2. The ALF-style rule uses the published core-e01 parameters on the three zero-filled maps. The PCA residual retains 99% of reference variance without whitening. The L2-r1 control converts each half-squared distance before taking the mean. | `metrics.csv`, experiment `scoring`. The same-representation nearest-neighbor row uses `--suite layers`. |
| Table 8, regional response | Post-hoc analysis at original resolution. The regional means use all pixels and the auxiliary AUC samples up to 8,192 pixels per stratum in each image. | `response_category_records.json` contains the per-category, per-reference records and sampling rule. `supporting_results.py` recomputes the macro summary. |
| Table 9, VisionAD common central region | Use the pinned author repository, checkpoint, input geometry, support/query branches and shared evaluation settings in `visionad_protocol.json`. | `metrics.csv`, experiment `common_crop`, contains all 243 official metrics rows. |
| Supplement, fixed layers and pairs | `--suite layers`, original groups 0–2. Use layer 4, 8 and feature-average results on both datasets and the fixed pairs on MVTec AD. The last layer and three-layer mean use the default suite. | `layer_aggregates_percent.json` contains verified per-reference macro values for the recorded fixed layers and pairs. |
| Supplement, LNAMD scoring | `--suite lnamd`, original MVTec AD groups 0–2. Extract tokens before patch L2, fit each view separately and use fixed neighborhoods 1, 3 and 5. The scoring rule is evaluated with the fixed reference banks. | `metrics.csv`, experiment `scoring`, methods `lnamd_l2_r1` and `lnamd_l2_r135`. |

All evidence files in the table are in `results/supporting/` unless an explicit path is given. The metric CSV stores values on the 0–1 scale. Dataset-level standard deviations are population SDs of the three reference-group macro averages. The mask experiment uses one reference group. Timing fields retain the units in their names. The provenance file records the source hashes for archived summary records.

The portable runner implements the full-image controls. The common-crop VisionAD experiment is supplied as a pinned protocol with official records. The response diagnostic is supplied at the category/reference level, and timing is supplied as fixed measurements. `supporting_results.py` recomputes their table summaries from those records. The four new cached-feature control suites were checked on a real MVTec AD cached sample, and LNAMD was checked on synthetic raw tokens. The real-image end-to-end checks in the README cover the default suite.
